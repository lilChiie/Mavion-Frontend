# Mavion Frontend

Frontend website untuk **Mavion**, platform berbasis Artificial Intelligence yang membantu pemantauan kebersihan destinasi wisata melalui dashboard interaktif dan peta OpenStreetMap.


---

# Repository

Backend Repository

https://github.com/lilChiie/Mavion-Backend

---

# Tech Stack

- React
- Vite
- Material UI
- React Router
- Axios
- OpenStreetMap (Leaflet)

---

# Requirements

- Node.js 22+
- npm

---

# Installation

## Clone Repository

```bash
git clone https://github.com/lilChiie/Mavion-Frontend.git

cd Mavion-Frontend
```

---

## Install Dependencies

```bash
npm install
```

## Run Project

```bash
npm run dev
```

Frontend berjalan pada

```
http://localhost:9000
```

---

# Features

- Authentication
- Dashboard Monitoring
- OpenStreetMap Visualization
- Report Management
- Trash Detection Result
- Sentiment Visualization
- Responsive User Interface

---

# Workflow

1. User login.
2. User membuat laporan.
3. Upload gambar lokasi.
4. Backend menjalankan AI Detection.
5. Hasil ditampilkan pada dashboard.
6. Lokasi ditampilkan pada peta OpenStreetMap.
